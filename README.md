# Nimva Risk Portfolio Intelligence

## Overview

A fictional specialty-insurance interactive data story created for the P302
capstone.

## Data Story

Portfolio growth can mask emerging risk. Explore aggregate portfolio health,
concentrated loss deterioration, supporting Data Quality context, and a
targeted, illustrative optimization scenario.

## Primary Experience

- Overview
- Portfolio Intelligence (Visual and Tabular)
- Data
- Data Quality detail
- Optimization scenario

## Technology

- Vue 3
- Vite
- JavaScript
- Local synthetic data
- Native SVG charts; no charting library

## Running Locally

```sh
npm install
npm run dev
```

## Production Build

```sh
npm run build
```

## Data

All company information, people, and portfolio data displayed in the
application are fictional and synthetic.

## Project Context

This implementation recreates and white-labels an existing UX concept as Nimva
Risk for a P302 Interactive Data Story case study.
